# 📄 AI Resume Analyzer

A beginner-friendly Python tool that analyzes a resume against a job description and identifies matching and potentially missing keywords.

## 🎯 Features

- Accepts resume text
- Accepts a job description
- Compares relevant keywords
- Calculates a basic resume match score
- Shows matched keywords
- Identifies potentially missing keywords
- Provides simple improvement feedback

## 🛠️ Technologies

- Python
- Natural Language Processing concepts
- Keyword Matching
- GitHub

## 🚀 How It Works

1. Enter your resume text.
2. Enter the job description.
3. The program extracts relevant keywords.
4. It compares the keywords with the resume.
5. A basic match score is calculated.
6. The program displays matched and potentially missing keywords.
